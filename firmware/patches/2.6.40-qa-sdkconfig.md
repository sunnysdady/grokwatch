# 2.6.40-qa build configuration

The local build uses upstream xiaozhi commit `39d23aee5b8682f77bbdf9cdc66799456b5ad408`, board `CONFIG_BOARD_TYPE_M5STACK_STOPWATCH=y`, NimBLE (`CONFIG_BT_ENABLED=y`, `CONFIG_BT_NIMBLE_ENABLED=y`), and the existing 16 MB custom partition table `partitions/v2/16m.csv`.

The generated local `sdkconfig.ble` is untracked. For 2.6.38 through 2.6.40-qa, the deliberate power-management change is `CONFIG_PM_ENABLE=y` (previously disabled). `CONFIG_PM_DFS_INIT_AUTO` remains disabled; the board code controls dynamic CPU frequency. Set this in the local board `sdkconfig.ble` before building. The local test-console build uses `-D SDKCONFIG=sdkconfig.ble -D GW_TEST_CONSOLE=1` and the upstream patch adds that opt-in flag.

Do not commit generated `sdkconfig.ble`, `sdkconfig.private`, credentials, or images. The test-console build is for local device validation and is not a public firmware artifact.
