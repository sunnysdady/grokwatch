# v2 → v3 自审记录（每轮：对照 HomeView 截图、PIL 测量、按 skill 清单批评、改、重渲染）
测量：HomeView Modular 绿主色 H180 S0.44 L0.31；取样 #134B49 S0.60 L0.18、#3F7F79 S0.34 L0.37。HomeView 的大块底色有叶纹明暗，主数字是纯白常规字重。
v2 底色 #17504B：S0.55 L0.20（一整面纯色，偏饱和）。v3 底色 #213F3B：S0.31 L0.19。v3 夜间底色 #100D0A：S0.23 L0.05。
主数字：v2 宽138 高93（屏宽的30%）；v3 宽160 高109（屏宽的34%，屏高的23%）。每页色阶：v2 4–6 个，v3 3–4 个（底色、一层白色叠加、文字、强调色）。

R1（taste-minimalist：大面积不用饱和色）：饱和度从 0.55 降到 0.33，明度不变。结果更安静，但薄荷黄的主数字在灰绿底上发脏。
R2（apple-design §15 字重/字距；frontend-design 字体要有意选）：主数字改成纯白 #F4F6F2；字体换成 Nunito Medium 150px（圆体，和待机的矢量圆角数字是同一种语言；OFL 授权）；辅助行改成同一字族的拉丁字母，比如 18.6 km 0:52，不再中英混排。另外试了上亮下暗的竖向渐变。结果：字重变轻，看起来接近 HomeView 的 68。
R3（emil：强调色只放在有意义的地方；ui-ux-pro-max：对比度≥4.5、不只靠颜色传达）：立即转弯不再整屏铺橙，只把箭头和数字变成橙色 #F7A04A，底色不变。导航的距离数字也用主数字字号。结果：150px 的 "350 m" 撑爆版面、压到了路名。
R4（apple-design：材质靠明度分层；HomeView：卡片是同色的亮层）：单位 m 拆成小字贴在数字右下；箭头上移；控制中心的瓷砖改成白色半透明叠加（开 23%、关 8%），在任何底色上都只亮一档。问题：RGB565 上竖向渐变出现明显色带，夜间中线还有一道硬边。
R5（frontend-design：照镜子再摘掉一件配饰）：去掉渐变，回到纯色底（不再分色带，也省掉渲染开销）。复查：8 张图没有被圆裁切，没有边框和阴影，每页只有一个主角加一行辅助，左右对称，外圈留白一致（速度环 r216，瓷砖角距圆心 ≤221）。
