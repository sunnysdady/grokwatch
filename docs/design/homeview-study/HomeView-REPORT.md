# Apple HomeView 设计研究 → GrokWatch 复刻方案

**结论**：HomeView 好看的原因不在玻璃特效，在于四条克制的规则：
1. 一张表盘只用一个主色，所有元素都是这个颜色的明暗变化。
2. 一个超大数字做绝对主角。
3. 圆角统一，层级靠明度区分。
4. 表盘随时间和距离变化。

这四条都能在 466 圆屏上用纯色和矢量图形做出来，不需要模糊效果。

标注说明：【确认】= 页面原文、截图或媒体报道里能直接看到；【推断】= 我的分析；【不确定】= 没有核实。

## 1. 核心设计理念（5 条）

1. **一眼可读，越近信息越多**
   - 【确认】S1 原文："Select features respond to your proximity to show more information the closer you get"；S3 的描述是远处显示简化信息、走近后显示细节。
   - 截图 09：天气表盘只有地名、54° 和一行说明；截图 26：计时器只有 10:56 和 15 MIN。
2. **大数字当主角，其余都退后**
   - 【确认】截图 17/18/19/35：68°、星期下面的"1"、整面铺开的 10:09、写满表盘的 12/3/6/9。主数字占屏高 30–60%（像素目测）。
   - 【推断】辅助文字只占主数字的 1/6–1/8，而且用的是同色低透明度。
3. **一张表盘只有一个颜色（单色调）**
   - 【确认】截图 17/35 的 Modular 表盘：紫色版底色 #5959CC，卡片在同一色相里做明暗，取样有 #3636A5、#7070E2、#8B8BF5；绿色版取样 #134B49、#226A64、#3F7F79、#649C96。截图 19：绿钟 #3E935C 配深绿 #15311F，粉钟 #C7AAA7 配同色系的针。
   - 截图 26：黑底上只有一个橙色 #F79431。
4. **温暖、像家里的东西，不像仪表**
   - 【确认】S1 原文："brings beauty to any room"、"Delights up the house"。截图 15/16 用人像大图，截图 28 是黄色 #DFC452 的 Pluribus 页面，截图 30 是莓紫 #53253E 的音乐页。
   - 【推断】饱和度偏中低、偏暖，没有荧光色。这正好是 Ultra 风格（橙色加大量信息）的反面。
5. **表盘是活的，会跟着时间变**
   - 【确认】S1 原文："Select faces change throughout the day. They wake with you in the morning, wind down with you at night"（截图 19）。S4 写到有一个表盘像日晷，数字会随时间淡入淡出。
   - 【确认】S1：亮度从 500 nit 到 0.3 nit。说明夜间就是把亮度压低，不是换成红色。

## 2. 为什么好看（具体机制）

**调色（PIL 在截图上取样，用量化取主色）**

| 场景 | 主色 / 层次 |
|---|---|
| Modular 紫（截图 17） | #3636A5 / #5959CC / #7070E2 / #8B8BF5 |
| Modular 绿（截图 35） | #134B49 / #226A64 / #3F7F79 / #649C96 |
| 天气（截图 09） | #4174A9 → #C2D3EA，竖向渐变 |
| 绿钟（截图 19） | #3E935C，配 #15311F |
| 粉钟（截图 19） | #C7AAA7 ~ #DDBEBB |
| 计时（截图 26） | #000000，配 #F79431 |
| 音乐（截图 30） | #53253E / #312029 / #66284A |
| 页面底 / 正文 | #F5F5F7 / #1D1D1F |

- 机制 A【推断】：同色相的卡片之间明度差大约 10–15%，所以层级清楚又不吵。
- 机制 B：不用纯白文字。正文接近 #FFFFFF，副文字大约是 50–60% 透明度（截图 17 中 "Living Room" 的灰度明显低于 "Thermostat"）。

**圆角**
- 【推断，像素估算】屏幕圆角约为屏宽的 12%。Modular 卡片圆角约为卡宽的 12–15%。卡片间距约为卡宽的 4%。圆角是连续曲线（squircle）【不确定，看起来像】。
- 外层和内层圆角是同心关系：内圆角 = 外圆角 − 间距（截图 35）。

**字体**
- 系统字是 SF Pro（截图 09 的天气、截图 21 的列表）。只用两档字号：巨大数字和小号标签，中间档很少。
- 大数字用 Regular 或 Medium（截图 09 的 54° 很细），小标签用 Semibold。这种"粗细反着配"是高级感的来源之一【推断】。
- 时钟数字是插画式的描边或胖圆体，见截图 17、19 和之前的参考图，所以走矢量绘制是对的。

**密度和留白**
- 截图 09：表盘中央只有 4 行字，留白超过 60%。
- Modular（截图 17）：2×3 网格，每格只有一个图标、一个主标签、一个副标签。

**动效**
- 【确认】Flow 表盘会对人的移动做出反应（S1、S3）。
- 【不确定】具体时长和曲线拿不到，因为影片没有逐帧分析。
- 【推断】Apple 的惯例是弹簧动画，约 0.3–0.5 s，没有回弹。

**不该误读的地方**
- Modular 卡片上的玻璃折射（截图 17、35）只是点缀。去掉之后，"同色明暗卡片"这个骨架依然成立。

## 3. 466 圆屏复刻配方

### 颜色

**白天**（深色 AMOLED 底，主题色可换）
- bg #000000
- surface = 主色在 22% 明度
- card = 主色在 30%，卡片按下时 38%
- 主文字 #F5F5F7，副文字 #F5F5F7 加 55% 透明度
- 推荐主题色：薄荷 #E8EFC4（待机），湖绿 #3F7F79 / #649C96，靛紫 #5959CC / #8B8BF5
- 警示色只有一个：#F79431，只用在超速、偏航和计时上

**夜间**（日出日落自动切换）
- 暖白 #FFE8C8，整体亮度 25–35%
- 卡片用 #1A1712
- 不出现蓝色和红色

### 圆角和间距
- 卡片圆角 = 卡片短边 × 0.14，最小 14px
- 胶囊按钮圆角 = 高度 / 2
- 网格单位 8px，卡片间距 8px
- 圆屏安全区：内接正方形大约 330×330，内容放在半径 ≤ 215 的范围里

### 字号（px）

| 层级 | 字号 | 字重 |
|---|---|---|
| hero 数字 | 150–190（矢量绘制，26px 笔画） | — |
| 次主数字 | 72 | Medium |
| 标题 | 28 | Semibold |
| 标签 | 22 | Semibold |
| 副标签 | 18 | Regular，55% 透明度 |

一屏最多 3 种字号。

### 卡片规则
- 纯色或两色线性渐变，不做模糊。
- 每张卡片只放 1 个图标、1 行主文字、可选 1 行副文字。
- 层级靠明度区分，不靠描边和阴影。

### 动效
- 页面切换 280ms，ease-out，cubic-bezier(0.32, 0.72, 0, 1)
- 按下缩放到 0.96，持续 100ms；松手 200ms 回弹
- 数字变化：交叉淡入，加 6px 位移，220ms
- 日夜切换：颜色渐变 1.5s
- 动画只做局部重绘，保证 60fps

### 保留 / 替换 / 删除
- **保留**：单色调、大数字、统一圆角、按时间变化、简洁标签
- **替换**：
  - 玻璃 → 扁平的同色明暗卡片
  - 照片背景 → 纯色或渐变
  - 接近感应 → 静止时大字少信息，抬腕或触摸时多信息（【推断】需要真机验证）
- **删除**：模糊、折射高光、大图、通知

### 三个页面怎么用
- **待机**
  - 薄荷色 #E8EFC4 上下叠放的矢量数字，占屏高约 70%
  - 下面一行 18px 小字：星期和电量
  - 夜间换成暖白 #FFE8C8 并调暗
  - 每次跨过日出或日落渐变切换
- **码表**
  - 一个 hero 数字（速度，约 170px）
  - 下方 2 个同色卡片：距离、时长
  - 主题湖绿；超速时只有速度数字变成 #F79431
- **导航**
  - 上半部分是大号转向箭头和距离数字（72px）
  - 下方一张卡片显示路名
  - 偏航时整张卡片变成 #F79431
  - 不放地图底图
