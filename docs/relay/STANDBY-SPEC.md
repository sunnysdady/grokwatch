# GrokWatch 待机规格 (2.6.19)

实现：`firmware/board/gw_sbsm.[ch]`（纯 C 状态机，无 LVGL 依赖）+ `nav_ui.cc` 胶水（事件输入、动作执行）。
测试：`sim/test_sbsm.c`（34 条路径），`sim/sim.c`（淡入淡出 + 吞触摸审计，GIF 输出 sb_enter.gif / sb_exit.gif）。
原则：**只有状态机能进入或退出待机。** 板级代码不再直接调光或息屏（删除了 WakeScreen、screen_off_、PowerSaveTimer 回调、待机点击钩子）。

## 1. 状态
| 状态 | 画面 | 背光 |
|---|---|---|
| ACTIVE | 当前页 | 用户亮度 |
| ENTERING | 待机钟 360 ms ease-out 淡入，盖在页面上 | 平滑降到 10% |
| STANDBY | 黑底大号 HH/MM，每分钟漂移 8 位防烧屏 | 10% |
| WAKING | 待机钟 220 ms ease-in 淡出（退出比进入快） | 平滑恢复 |
不单独设"灭屏"状态：AMOLED 黑像素本身不耗电，10% 亮度下只有数字在发光。

## 2. 进入
| 触发 | 条件 | 结果 |
|---|---|---|
| 空闲 20 s（所有页面相同；USB 和电池供电都生效） | 无例外 | ENTERING；记住当前页；打开的控制中心或弹层先关掉 |
| 红键单击 | 已唤醒，且距上次切换超过 250 ms | ENTERING + 15 ms 震动（导航中也允许手动进入） |
| 例外：导航中、骑行中（5 s 内收到过速度帧）、GrokBot 在听/说/连接、控制中心/弹层/关机确认开着 | — | 不自动进入；例外结束后重新完整计时 20 s |
| 任意触摸按下（醒着时） | — | 空闲计时清零 |

## 3. 退出（全部经过 WAKING，再回到 ACTIVE）
| 触发 | 回到哪一页 | 该输入本身 |
|---|---|---|
| 触摸 | 进入待机前的那一页 | **吞掉**：待机层在淡出期间仍可点击，点击和滑动都不会落到下面的页面 |
| 红键单击 | 进入前的页 | 只唤醒 |
| 黄键（单击/双击/长按） | 进入前的页 | 只唤醒，不翻页、不回主页、不调音量 |
| 蓝键按下 | 进入前的页，随即切到 GrokBot 页 | 唤醒并**直接开始说话** |
| 红键双击 | 进入前的页 | 唤醒并弹出关机确认 |
| 新导航开始 / 转弯预告 / 立即转弯 | **导航页** | — |
| 语音回复到达（assistant 字幕） | **GrokBot 页** | — |
| 骑行总结 | 进入前的页（总结弹层盖在上面） | — |
| 普通导航数据帧（距离刷新） | 不唤醒 | — |
| 通知 | 本固件没有通知通道；以后加上时走同一个事件接口 | — |

## 4. 待机中的输入
- 红键长按：属于 PMIC 硬件行为（关机），固件不拦截。
- 滑动：不生效。第一次触摸只负责唤醒，被吞掉。
- 防抖：任何状态切换后 250 ms 内，红键再按一次会被忽略。超过 250 ms 后，在淡入过程中按红键可以反向唤醒。

## 5. 功耗与连接
- 刷新：进入完成后，待机钟下面的页面对象会被隐藏，秒针和页面定时器不再在不透明层后面重绘刷屏；待机钟只在分钟变化时重绘数字区域。唤醒淡出开始时，先恢复页面显示，让它透过淡出的待机钟露出来。
- Wi‑Fi、BLE 和唤醒词在待机中**保持开启**。旧的 PowerSaveTimer 曾在 60 s 后让 CPU 进入 light sleep 并关闭唤醒词，现已删除，因此待机不会切断导航数据。代价是待机电流比旧方案略高（未实测）。

## 6. 按键映射（以代码为准，m5stack_stopwatch.cc）
| 键 | 醒着时 | 待机中 |
|---|---|---|
| 黄 G2 | 单击下一页 / 双击回主页 / 长按调音量；关机确认时单击=取消 | 唤醒 |
| 蓝 G1 | 按住说话、松开发送；关机确认时=确认关机 | 唤醒并开始说话 |
| 红（PMIC） | 单击进入待机；关机确认时单击=取消；双击=关机确认；长按=硬件 | 单击唤醒 / 双击唤醒并弹出关机确认 |

## 7. 日志
每次状态切换都会打印一行 `GW-SB: <原因> -> act=0x.. state=..`，淡入淡出结束时打印 `GW-SB: state=..`，可通过串口被动核对。
