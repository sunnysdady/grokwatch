# 0x50 USAGE — Grok Bot 用量（App → 手表，固件 2.6.11 起）

帧外层与其他 BLE 帧相同：`type(1) len_lo(1) len_hi(1) payload`。

payload：
| 字节 | 含义 |
|---|---|
| 0 | 用量百分比 0–100；`0xFF` = 未知（手表显示「—」） |
| 1.. | 可选：重置时间，UTF-8，NUL 结尾，≤15 字节，如 `18:00`、`周一`、`10/27` |

- 手表只存内存（RAM），不写 NVS，重启后显示「—」直到 App 再发。
- 数据来源由 App 决定（v1：用户在官方页面看到后手动录入），App 不得编造数字；拿不到就发 `0xFF` 或不发。
- 建议 App 在连接建立时和数值变化时各发一次。
- 主表盘胶囊显示：`Grok Bot 42% · 18:00`；无重置时间时 `Grok Bot 42%`；未知时 `Grok Bot —`。
- 旧固件不认识 0x50，直接忽略，无副作用。

例：42%，18:00 重置 → `50 07 00 2A 31 38 3A 30 30 00`
