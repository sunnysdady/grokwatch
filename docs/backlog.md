# GrokWatch 需求池 (RC6.1 之后)

定位：骑行大屏伴侣，配合 Apple Watch。核心是导航码表 + 一键跟 Grok 对话。通知是可选功能，默认关闭。

## 性能预算
- 输入到响应 <100 ms；有动画就 ≥30 fps，没有就直接切换
- 堆余量 ≥20%，min-free 要上报；不加常驻任务；功能关闭时完全空闲
- 模拟器实测：listening 每帧脏区约 11.9%，thinking 约 10.6%；共 141 个对象；LVGL 堆 36.5 KB/1 MB (PSRAM)；Grok 页隐藏时 timer 暂停
- 板上实测 (RC6)：SRAM 空闲 65,959 B，最低 33,468 B
- 待板上验证：fps、RC6.1 的 min-free、触摸延迟
- RC6.1 OTA 镜像占 slot 95%，只剩约 207 KB

## 用户画像
1. 深圳电动车通勤：要大号转向和距离，提前震动，不想掏手机
2. 周末公路车：要速度、时间、里程和骑行总结，屏幕要省电
3. 夜骑：需要红色夜间模式和低亮度，不能刺眼
4. Grok 重度用户：一按就能说，回复要有声音和字幕，离线要一眼看出来
5. 新手创客：要 README 清楚、能一键编译和 OTA，不要泄露密钥
